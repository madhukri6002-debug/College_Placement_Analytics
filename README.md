# College Placement Analytics

> ⚠️ **SAMPLE DATA ONLY** — All student names, companies, and figures in this project are entirely fictitious and are used for demonstration purposes only. They do not represent real college placement records.

---

## What This Project Does

College Placement Analytics is a simple, beginner-friendly data analytics dashboard that shows:

- **Overall placement rate** — how many students got placed
- **Average & highest salary package** — in LPA (Lakhs Per Annum)
- **Branch-wise analytics** — placement rate and average salary for each branch
- **CGPA vs Salary** — scatter chart showing the correlation
- **Top recruiters** — companies that hired the most students
- **Offer type split** — On-Campus vs Off-Campus placements
- **Filterable student table** — search by name, filter by branch or status

## How to Run

### Step 1 — Generate the JSON Summary (Python)

This reads `data/placement_data.csv` and creates `reports/placement_summary.json`.

```bash
# Windows
py src/analyze.py

# Mac / Linux
python3 src/analyze.py
```

Expected output:
```
College Placement Analytics -- Analysis Script
NOTE: Uses SAMPLE DATA only -- not real placement records.

  Loading data from: .../data/placement_data.csv
  Loaded 60 student records.

  Summary saved to: .../reports/placement_summary.json

  -- Overall Stats -----
     Total students   : 60
     Placed           : 48  (80.0%)
     Avg package      : 12.44 LPA
     Highest package  : 45.0 LPA
  ...
```

### Step 2 — Start the Web Server (Node.js)

```bash
node server.js
```

Then open your browser and go to:

```
http://localhost:3000
```

To use a different port:
```bash
# Windows
set PORT=3001 && node server.js

# Mac / Linux
PORT=3001 node server.js
```

## What Each File Does

### `data/placement_data.csv`
Raw sample data with 60 fictional students across 5 branches (CSE, ECE, ME, CE, EE, IT). Each row has:
- `student_id`, `name`, `branch`, `cgpa`
- `placed` (Yes/No), `company`, `package_lpa`, `offer_type`

### `src/analyze.py`
- Uses only Python standard library (`csv`, `json`, `os`, `collections`)
- Computes overall stats, branch stats, top recruiters, CGPA/salary pairs
- Writes everything to `reports/placement_summary.json`

### `server.js`
- Uses only Node.js built-in modules (`http`, `fs`, `path`)
- Serves `frontend/` as static files
- Exposes `GET /api/summary` → streams `placement_summary.json`

### `frontend/index.html`
- Single-page responsive dashboard
- Loads Chart.js from CDN (no install needed)
- Loads `style.css` and `script.js`

### `frontend/script.js`
- Fetches `/api/summary` and renders 5 charts + 1 table
- Branch filter, status filter, and name/company search

## Customising the Data

To use your own data, edit `data/placement_data.csv` following the same column headers, then re-run `py src/analyze.py` and refresh the browser.
